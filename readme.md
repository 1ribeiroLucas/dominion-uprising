# Dominion: Uprising

**Dominion: Uprising** é um *MOBA 5v5* com mecânicas de Pontos de Captura. Baseado em processos civilizatórios reais, traz reflexões sobre as consequências da desconexão com os povos originários e a ancestralidade.

**Engine**: Unity  
**Equipe**: MagicOwl Games  
**Data prevista para a Demo**: 01/01/2027
